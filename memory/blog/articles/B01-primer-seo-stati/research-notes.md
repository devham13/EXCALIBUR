**Intent:** `how_to` — пользователь хочет **пошаговую систему**: интент → семантика → outline → текст → мета/schema → GEO-чанки → финальный чеклист. Вторичный: связка «seo текст для блога» + «geo оптимизация статьи» в одном материале, без двух отдельных проектов.

**Пробел для Excalibur:** один **action-first workflow** «SEO + GEO в одной статье», где **читабельность** (инфостиль, короткие абзацы, «острова смысла») — не абстракция, а проверяемые пункты чеклиста; сама B01 — **эталон** формата (режим B).

## 4. Угол статьи (utility-only, режим B)

**Главный угол:** SEO-статья 2026 = **читаемый longread**, который закрывает запрос человека **и** упакован для нейропоиска. Не «ещё один список ключей», а **единый workflow за одну сессию**: интент → семантика → outline → текст по блокам → мета/schema → GEO-чанки → **чеклист 15–20 пунктов**.

**Почему отличается от конкурентов:**

- Яндекс — канон SEO без GEO-слоя; GEO-гайды не учат писать текст с нуля.  
- Агентские longread'ы перегружены E-E-A-T-кейсами и CTA.  
- H1 «**которые читают люди**» слабо раскрыт в SERP; наш фокус: **читабельность как измеримая практика** (инфостиль, абзацы 3–6 предложений, island test) + техника в одном проходе.  
- Сама статья B01 — **эталон** режима B: 8 500–9 500 знаков, FAQ, BlogPosting + FAQPage.

**H2-каркас (из карточки + research):**

1. Зачем SEO и GEO в одной статье (не два проекта, один контент)  
2. Структура longread: H1–H3, lead 40–60 слов, списки, таблицы  
3. FAQ и schema — зачем и как (JSON-LD, не в body)  
4. Чеклист перед публикацией (15–20 пунктов)

**Подтемы внутри блоков:** Wordstat/интент, Title/Description, E-E-A-T lite, перелинковка, alt, проверка в AI-выдаче.

## 6. FAQ-кандидаты (5–7)

1. **Сколько символов должно быть в SEO-статье?** — универсальной нормы нет; ориентир — полнота ответа и конкуренты в SERP; для how-to longread Excalibur — 8 500–9 500 знаков.  
2. **Что такое GEO в SEO?** — GEO дополняет SEO: цель — цитирование в AI-ответах при базе из индексируемого структурированного контента.  
3. **Нужно ли переспамить ключевые слова в 2026 году?** — нет; естественные вхождения + LSI; keyword stuffing хуже для GEO (Princeton GEO-bench).  
4. **Чем Title отличается от H1?** — Title для сниппета (~60–65 знаков), H1 — на странице; не дублировать.  
5. **Какие schema нужны для SEO-статьи блога?** — BlogPosting (или Article) + FAQPage.  
6. **Как проверить статью перед публикацией?** — чеклист: семантика, мета, структура, FAQ, schema, ссылки, читабельность, island test.  
7. **Как писать, чтобы читали люди, а не только роботы?** — инфостиль, короткие абзацы, таблицы/списки, прямой ответ в lead, без воды и штампов.

## 8. Utility gate (research)

**utility_verdict:** PASS

**reader_outcome:** Читатель определит поисковый интент, соберёт семантику и outline по топ-10 SERP, напишет SEO-статью блоками с GEO-структурой (lead, автономные абзацы, FAQ), оформит Title/Description и JSON-LD, пройдёт финальный чеклист и сможет опубликовать материал, который читают люди и который пригоден для AI-выдачи.

**action_outline (how-to, 8 шагов):**

1. **Зафиксировать интент:** открыть топ-10 по «как писать seo статьи», классифицировать запрос (информационный/коммерческий), записать 1–2 «работы», которые должен выполнить текст.  
2. **Собрать семантику:** primary + 5–10 LSI из Wordstat/SERP («Вместе с этим ищут»); выписать вопросы для FAQ.  
3. **Снять структуру конкурентов:** скопировать H2 топ-5, отметить таблицы/FAQ/объём; составить **свой** outline (не копия одного URL).  
4. **Написать lead и outline:** lead 40–60 слов с прямым ответом; H2 = подзадачи; под каждым H2 — 1 строка «что сделает читатель».  
5. **Писать по блокам:** один H2 за сессию; абзацы 3–6 предложений; после каждого тезиса — рекомендация «делать / не делать»; добавить таблицу или список.  
6. **Добавить GEO-слой:** 3–5 автономных «островов»; FAQ 5–7 пар (ответ ≤80 слов); убрать отсылки «см. выше».  
7. **SEO-финализация:** Title ≤60 символов, Description 140–160, H1 ≠ Title, URL латиница, alt, внутренние ссылки, JSON-LD BlogPosting + FAQPage.  
8. **Финальный чеклист:** прогнать 15–20 пунктов (семантика, мета, island test, факты, AI-штампы); опционально — тестовый промпт в Яндекс Нейро / AI Overviews.
