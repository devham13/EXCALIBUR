За 20-40 минут можно пройти полный цикл: native install на своей ОС, вход в аккаунт, CLAUDE.md, первый MCP-сервер, hook и проверка `claude -p` для автоматизации. TL;DR / Быстрый инсайт: Claude Code - agentic CLI от Anthropic: агент читает репозиторий и выполняет команды в терминале с вашим подтверждением. Ставьте native installer (не sudo npm), проверяйте PATH через `claude doctor`, настраивайте CLAUDE.md и `.mcp.json`, hooks в settings.json и headless через `claude -p`. Бесплатный план Claude.ai Claude Code не включает - нужен Pro ($20/мес) или Console API.

Claude Code - программа в терминале (CLI - "командная строка"), не браузерный чат. MCP - "розетка" для внешних tools (см. MCP в Cursor), конфиг: `.mcp.json` и `claude mcp add`. Hooks - скрипты на события без участия Claude.

1. Сравните Claude Code, Cursor и чат Claude - что выбрать

Выберите по месту работы, не по рейтингу.

Критерий Claude Code (CLI) Cursor (IDE) Claude.ai (чат)
Где работает Терминал, CI, VS Code extension IDE (форк VS Code) Браузер и приложения
Правка файлов и bash Да, с approve Да, Agent mode Ограниченно (artifacts)
MCP `.mcp.json`, `claude mcp add`, `/mcp` `.cursor/mcp.json` Connectors (другой UX)
Headless / CI `claude -p`, JSON output Cloud Agents (отдельно) Нет
Hooks `.claude/settings.json` Rules (другой API) Нет
Итоговый вердикт: IDE каждый день - Cursor; terminal, git-воркфлоу, серверы и CI - Claude Code; брейншторм и документы - чат. Оба редактора могут сосуществовать на одном проекте.

Делайте: ставьте Claude Code, если нужны скрипты и headless. Не делайте: ждать от чата Claude полноценного agentic-доступа к репозиторию.

2. Установите Claude Code CLI на macOS, Linux и Windows

Требования: macOS 13.0+, Windows 10 1809+, Ubuntu 20.04+, 4+ ГБ ОЗУ, интернет. Claude Code не входит в бесплатный Claude.ai - нужен Pro ($20/мес), Max (от $100/мес) или Console/API (pricing).

Метод Команда Auto-update Когда выбирать
Native (рекомендуется) install.sh / install.ps1 Да, в фоне Первый раз на любой ОС
Homebrew `brew install --cask claude-code` Ручное macOS, уже используете brew
WinGet `winget install Anthropic.ClaudeCode` Ручное Windows без PowerShell-скриптов
npm `npm install -g @anthropic-ai/claude-code` Ручное (`@latest`) Уже есть Node.js 22+

Native installer (quickstart):

macOS / Linux / WSL 2:
`curl -fsSL https://claude.ai/install.sh | bash`
Windows PowerShell:
`irm https://claude.ai/install.ps1 | iex`
Windows CMD:
`curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd`
  1. Шаг 1: Выберите native install, если Node.js 22+ ещё нет.
  2. Шаг 2: Выполните команду для своей ОС из таблицы выше.
  3. Шаг 3: Закройте и откройте терминал - обновится PATH.
  4. Шаг 4: Проверьте: `claude --version`.
  5. Шаг 5: При "command not found" добавьте `~/.local/bin` (Unix) или `%USERPROFILE%\.local\bin` (Windows) в PATH.
  6. Шаг 6: Запустите `claude doctor` - диагностика окружения.

Делайте: native installer для автообновлений. Не делайте: `sudo npm install -g` - риск прав и безопасности (setup docs).

3. Авторизуйтесь и инициализируйте проект (CLAUDE.md, permissions)

Первый запуск: введите `claude` - откроется браузер для входа. Смена аккаунта в сеансе: `/login`. Если задан `ANTHROPIC_API_KEY`, CLI может конфликтовать с подпиской - снимите переменную или явно выберите метод auth.

Workflow от нуля до первого агента:
install → auth (`claude`) → `cd` в репозиторий → `/init` или CLAUDE.md → permissions в `.claude/settings.json` → MCP → hook → `claude -p` тест

CLAUDE.md (`./CLAUDE.md` или `./.claude/CLAUDE.md`) - память проекта: build/test, стиль. Автогенерация: `/init`. Папка `.claude/` - settings и локальные файлы.

Пример минимального CLAUDE.md:
`# Проект`
`npm test` — запуск тестов
`npm run build` — сборка
Коммиты: conventional commits, язык — русский в docs/

Делайте: опишите в CLAUDE.md реальные команды build/test - агент перестанет угадывать. Не делайте: класть секреты в CLAUDE.md - только команды и conventions.

4. Подключите MCP-сервер через claude mcp add и .mcp.json

MCP подключает браузер, GitHub, docs. Конфиг проекта - `.mcp.json` в корне repo, не в `.claude/`.

Scopes: `local`, `project` (.mcp.json), `user`. CLI:

`claude mcp add --scope project --transport http myserver https://example.com/mcp`
`claude mcp add --scope project mytool -- npx -y @modelcontextprotocol/server-filesystem ./src`

Проверка в сеансе: `/mcp`. Отличия от Cursor - в гайде MCP Cursor.

Делайте: один MCP под задачу, approve tools при первом вызове. Не делайте: копировать `.cursor/mcp.json` в `.claude/` - пути и формат отличаются.

5. Настройте hooks и проверьте headless-режим (claude -p)

Hooks - ключ `"hooks"` в `.claude/settings.json` или `~/.claude/settings.json`. События: PreToolUse, SessionStart. Список: `/hooks`.

Headless (без интерактива) - флаг `-p` ("print mode"):

`claude -p "кратко опиши структуру репозитория"`
`claude -p "запусти npm test и верни только ошибки" --output-format json`

Plan Mode - только план без правок до approve:

`claude -p "план рефакторинга auth модуля" --permission-mode plan`

Лимиты - скользящее 5-часовое окно; CLI и чат делят пул (FAQ).

Делайте: тестируйте `-p` локально перед CI. Не делайте: гонять headless на Pro без `--max-budget-usd` в продакшен-скриптах - легко упереться в лимит.

6. Исправьте типичные ошибки (npm, PATH, Node, лимиты)

  • `claude: command not found` - PATH: `~/.local/bin` или `%USERPROFILE%\.local\bin`; затем `claude doctor`
  • EBADENGINE при npm - нужен Node.js 22+ (с v2.1.198 пакета), не 18 из старых гайдов
  • `sudo npm install -g` - переустановите через native installer без sudo
  • 403 на curl install - см. troubleshoot-install в setup docs
  • Windows без Git Bash - shell tool = PowerShell; с Git for Windows - Bash tool
  • WSL 2 - sandboxed command execution; WSL 1 - без sandbox
  • Конфликт ANTHROPIC_API_KEY и Pro - unset env или выберите один auth
  • MCP не виден - `.mcp.json` в корне repo, не в `.claude/`; проверка `/mcp`
  • npm update не обновляет CLI - используйте `npm install -g @anthropic-ai/claude-code@latest`
  • Исчерпан лимит - Settings > Usage или апгрейд Max
  • Desktop app - альтернатива CLI без терминала (macOS/Windows/Linux)

Делайте: `claude doctor` после смены PATH. Не делайте: обход подписки через сторонние API.

7. Что делать дальше

  1. Установите native CLI и пройдите `claude doctor` без ошибок.
  2. Сгенерируйте CLAUDE.md через `/init` под ваш stack.
  3. Подключите один MCP (filesystem или docs) и проверьте `/mcp`.
  4. Добавьте hook на PreToolUse для git или тестов.
  5. Запустите `claude -p` из shell-скрипта - прототип CI.

Частые вопросы

Как установить Claude Code на Windows?

Откройте PowerShell от пользователя и выполните `irm https://claude.ai/install.ps1 | iex`. Альтернатива: WSL 2 + `curl -fsSL https://claude.ai/install.sh | bash`. Перезапустите терминал, проверьте `%USERPROFILE%\.local\bin` в PATH и `claude doctor`.

Нужен ли Node.js для Claude Code?

Для native install - нет. Для npm-пути да: Node.js 22+ (пакет `@anthropic-ai/claude-code` с v2.1.198). Обновление: `npm install -g @anthropic-ai/claude-code@latest`, не `npm update -g`.

Чем Claude Code отличается от Cursor?

Cursor - IDE-first с Agent в редакторе. Claude Code - terminal/CI-first: headless `claude -p`, hooks, git-воркфлоу на сервере. MCP общий по идее; конфиги разные (.mcp.json vs .cursor/mcp.json).

Как подключить MCP к Claude Code?

Выполните `claude mcp add --scope project ...` или создайте `.mcp.json` в корне репозитория. В сеансе одобрите tools и проверьте `/mcp`. Не кладите MCP config в папку `.claude/`.

Бесплатно ли Claude Code?

Нет. Бесплатный план Claude.ai Claude Code не включает. Нужен Claude Pro ($20/мес), Max (от $100/мес), Team/Enterprise или оплата через Console/API credits.

Что делать, если claude: command not found?

Добавьте в PATH каталог `~/.local/bin` (macOS/Linux) или `%USERPROFILE%\.local\bin` (Windows). Перезапустите терминал. Запустите `claude doctor` - он подскажет, что не так с установкой.

Можно ли запускать Claude Code без интерактива?

Да: `claude -p "ваша задача"`. Для CI добавьте `--output-format json` и при необходимости `--permission-mode plan` или `--max-budget-usd` для контроля расхода.
