# Supahero → hero первого экрана (5 примеров)

Дата отбора: **2026-11-19**. Источник: [Supahero](https://supahero.io/).  
Контекст: «Лирейт», ИС и товарные знаки; аудитория — предприниматели и МСБ РФ; визуальный ориентир — светлый спокойный B2B из [`DESIGN.md`](../../../DESIGN.md) (RS-01) + trust metrics на текущем сайте.

**Метод:** композиция — по превью `*.webp` на странице Supahero; тексты CTA/иерархия — по превью и/или live-сайту (HTTP **200** 2026-11-19). Точные px, шрифты и HEX с live — **не извлечены** (без CSS-аудита).

**Права:** скриншоты принадлежат исходным сайтам и/или ScreensDesign/Supahero; в продакшен «Лирейт» — **своя** графика и OFL-шрифты из `DESIGN.md`.

## SH-01 — Canopy (институциональный B2B)

| | |
|--|--|
| Supahero | https://supahero.io/hero/canopy (**200**) |
| Исходный сайт | https://www.canopyservicing.com/ (**200**) |
| Превью | CDN Supahero `canopy.webp` (проверено 2026-11-19) |

**Композиция (из превью Supahero):** светлый фон с едва заметной сеткой; **центрированный** стек — pill-анонс «Guide», крупный H1, серый подзаголовок, пара CTA («Get Started» + текстовая ссылка). Ниже — **трёхколоночный** визуальный ряд: фото человека с UI-оверлеем | схематичная графика | скрин продукта. Внизу — **логотипы партнёров** (monochrome).

**Иерархия:** H1 доминирует; primary CTA — чёрная кнопка; вторичное действие — текст.

**Фото:** реальный портрет в левой карточке — человеческое доверие + «интерфейс как доказательство».

**Применимость для «Лирейт»:** посетитель хочет **понять экспертизу и масштаб** (Роспатент, договоры ИС) — тот же приём: центральный оффер «регистрация ТЗ / патентов», под ним **три доказательства**: фото юриста / схема этапов / карточка услуги. Trust bar — клиенты или «с 2015 г., N специалистов» из `DESIGN.md`. Соответствует RS-02/RS-03 без копирования зелёного акцента Canopy.

**Не проверено:** контраст серого подзаголовка WCAG на live Canopy; мобильный стек колонок.

## SH-02 — Phamily (экспертное сопровождение B2B)

| | |
|--|--|
| Supahero | https://supahero.io/hero/phamily (**200**) |
| Исходный сайт | https://phamilypharma.com/ (**200**) |

**Композиция (из превью Supahero):** **центрированный** H1 с **цветовыми подложками** на ключевых словах; подзаголовок про «personalized support, dedicated experts»; **два равнозначных CTA** («acheteur» / «vendeur»). Крупные **иллюстративные руки** по краям на тёмно-зелёном фоне.

**Иерархия:** эмоциональный заголовок > пояснение > выбор сегмента аудитории.

**Фото:** в hero превью **нет** — акцент на иллюстрации и типографике.

**Применимость для «Лирейт»:** копия Supahero описывает **экспертов и сопровождение** — близко к «оплата за результат» и консультации для МСБ. Заимствовать **структуру**: один H1 + короткий support-текст + **два CTA** («Оставить заявку» / «Обратный звонок» или «ТЗ» / «Патенты»). **Не** копировать игривые иллюстрации и агрессивный зелёный/розовый — **требует утверждения**; палитра из `DESIGN.md` (`#fafaf9`, `#1e4a7a`).

**Не проверено:** читаемость H1 на мобильном при длинной кириллической строке; лицензия иллюстраций Phamily.

## SH-03 — Cobalt (оффер для владельца малого бизнеса)

| | |
|--|--|
| Supahero | https://supahero.io/hero/cobalt (**200**) |
| Исходный сайт | https://joincobalt.com/ (**200**) |

**Композиция (из превью Supahero):** **тёмный** фон, перспективная сетка; **центрированные** H1 + подзаголовок с явной формулировкой *small business owner*; pill-CTA «Join the waitlist»; **крупный mockup продукта** (дашборд) в нижней половине.

**Иерархия:** текстовый оффер вверху → продуктовое доказательство внизу (не hero-фото).

**Фото:** не используется в верхней зоне; LCP-кандидат — **иллюстрация/UI mockup** (оценить вес при внедрении).

**Применимость для «Лирейт»:** аудитория **предприниматель МСБ** — перенять **ясный подзаголовок «для владельцев бизнеса»** и идею «сложная услуга выглядит просто». Для айдентики предпочтительна **светлая** RS-01 canvas вместо dark mode Cobalt (**требует утверждения**). Mockup заменить на «карта этапов регистрации ТЗ» или форма заявки, не финтех-дашборд.

**Не проверено:** актуальность live Cobalt vs скрин Supahero; размеры/формат mockup для LCP.

## SH-04 — Better Stack (центр + социальное доказательство)

| | |
|--|--|
| Supahero | https://supahero.io/hero/better-stack (**200**) |
| Исходный сайт | https://betterstack.com/ (**200**) |

**Композиция (из превью Supahero):** **тёмный** фон; **центр**: 3D-логотип, H1, подзаголовок, **inline-форма** (email) + primary CTA «Start for free»; боковые **симметричные** абстрактные формы; внизу — **logos strip**.

**Иерархия:** H1 → подзаголовок → единственный low-friction CTA (email).

**Фото:** нет; декоративная 3D/градиентная графика.

**Расхождение live / Supahero (проверено 2026-11-19):** на **текущем** betterstack.com hero — другой H1 («The AI SRE observability stack»), **карусель** скринов вместо симметричных «крыльев» из превью. Для PR использовать **Supahero как зафиксированный референс композиции**, live — только для проверки актуальности CTA-паттерна.

**Применимость для «Лирейт»:** посетитель готов **оставить контакт** — паттерн «короткая форма + главная кнопка» уместен для «Обратный звонок» (телефон/email). Logos strip → **кейсы, отрасли, цифры доверия**. Визуал — светлый вариант RS-01, без тёмного devtools-стиля.

**Не проверено:** контраст фиолетового CTA на тёмном (в превью); политика шрифтов Helvetica Now на Better Stack (коммерческий).

## SH-05 — ai.work (сегментация + упоминание Legal)

| | |
|--|--|
| Supahero | https://supahero.io/hero/ai-work (**200**) |
| Исходный сайт | https://www.ai.work/ (**200**) |

**Композиция (из превью Supahero):** **тёмный** фон; навигация в **капсуле**; контент **снизу слева**: H1, подзаголовок с перечислением функций (**включая Legal**); CTA «Book a demo» / «Request Access». Справа — крупный полупрозрачный **звёздный/астериск** watermark.

**Иерархия:** асимметрия — текст в нижней левой зоне, пустое «воздух» справа под watermark.

**Фото:** нет.

**Применимость для «Лирейт»:** полезен **не AI-тон**, а **ниша в подзаголовке** («товарные знаки, патенты, договоры ИС») и **низкая плотность** hero для спокойного юр. стиля. CTA оставить человеческими («Заявка», «Позвонить»), не «Request Access». Светлый фон + `--color-accent` из `DESIGN.md`.

**Не проверено:** соответствие live ai.work скрину на дату публикации Supahero (июнь 2025); контраст серого body-текста.
