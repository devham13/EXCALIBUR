# Supahero — источник референсов hero (первый экран)

| Поле | Значение |
|------|----------|
| URL | https://supahero.io/ |
| Назначение | Курируемая библиотека **скриншотов hero-секций** реальных сайтов: композиция, иерархия заголовка/CTA, роль иллюстраций и фото |
| Дата проверки | **2026-11-19** |
| Контакт (на сайте) | alex@screensdesign.com |
| Родительский продукт | Баннер: [Supahero is now part of screensdesign](https://screensdesign.com/?utm_source=supahero&utm_medium=banner&utm_campaign=screensdesign) |

## Что это даёт проекту

Supahero описывает **макро-композицию первого экрана**, не токены целиком (для tokens — [Refero Styles](refero-styles.md)) и не motion (для motion — [Design Spells](design-spells.md)).

Курируемая подборка для юридического сайта «Лирейт»: [`../legal-site-curated/supahero-curated.md`](../legal-site-curated/supahero-curated.md).

Проектный черновик: [`DESIGN.md`](../../../DESIGN.md).

## Как читать карточку

| Элемент | Содержание |
|---------|------------|
| `https://supahero.io/hero/<slug>` | Страница примера (**200** проверено), превью `*.webp` на R2 CDN |
| «Visit Website» | Ссылка на **исходный** продукт (проверять HTTP перед цитированием) |
| Анализ композиции | По превью Supahero + выборочная сверка с live-сайтом; если live **расходится** со скриншотом — указано в курации |

**Ограничение:** Supahero не публикует отдельный DESIGN.md; точные px/HEX **не** выводить из скриншота без live/CSS-аудита.

| `https://screensdesign.com/terms/` | **200** (Effective 2026-08-12, Increasebrand OÜ): сервис — библиотека UI «для inspiration, analysis»; **запрещены** копирование/сбор датасетов и перепродажа контента (§6–7); Third-Party App Content — fair use/исследование, **риск производных работ на пользователе** (§9) |

**Вывод для репозитория:**

- Хранить **описания, ссылки и id SH-xx**; **не** коммитить файлы `heroes/*.webp` с CDN Supahero в продакшен-тему.
- Не копировать фотографии, иллюстрации и шрифты с исходных сайтов без права; hero-изображения для `PUBLIC_SITE_URL` — только **собственные** или лицензированные стоки.
- Скриншоты на Supahero — **наблюдение** чужих UI; при внедрении композиции по мотивам примера указывать в PR: `design_ref: SH-xx` + URL страницы Supahero + исходный сайт.
